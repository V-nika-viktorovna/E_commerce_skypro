# Проект "E-commerce_skypro"

## Описание:

Проект домашнего задания к четвертому модулю "Объектно-ориентированное программирование" 
Данный проект создан при прохождении обучения в онлайн-школе SkyPro.

Проект содержит классы:

1. Product, в нем определены следующие свойства:
   - название (name),
   - описание (description),
   - цена (price),
   - количество в наличии (quantity).

2. Category, в нем определены следующие свойства:
   - название (name),
   - описание (description),
   - список товаров категории (products).

3. IterCategory, с его помощью можно перебирать товары одной категории

4. Smartphone, класс-наследник от исходного класса Product.
Помимо наследуемых свойств, имеет следующие:
   - производительность (efficiency),
   - модель (model),
   - объем встроенной памяти (memory),
   - цвет (color).

5. LawnGrass, класс-наследник от исходного класса Product.
Помимо наследуемых свойств, имеет следующие:
   - страна-производитель (country),
   - срок прорастания (germination_period),
   - цвет (color).

6. BaseProduct, базовый абстрактный класс, который является родительским для класса продуктов.

Классы «Smartphone» и «LawnGrass» остаются наследниками класса Product 
и тем самым наследуют все свойства данного абстрактного класса.

"def add" - общая функциональность, которая есть у каждого продукта, и описана в абстрактном классе.

7. MixinPrint, класс-миксин, который при создании объекта, то есть при работе метода "def init",
печататает в консоль информацию о том, от какого класса и с какими параметрами был создан объект.
Миксин добавлен в цепочку наследования класса Product.

8. Order, класс в котором еть ссылка на то, какой товар был куплен, количество купленного товара,
а также итоговая стоимость.

9. Base_Category, для классов «Order» и «Category» выделено общие свойство (def str)
и вынесено их в общий абстрактный класс.

Проект содержит следующие функции:

1. tget_data_object_class() модуль utils.
"""Функция принимает путь до файла json, считывает данные из json файла
    и создает объекты классов."""
